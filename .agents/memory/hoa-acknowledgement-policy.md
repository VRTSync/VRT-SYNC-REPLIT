---
name: HOA acknowledgement policy
description: Owner-approved meaning of acknowledgement and the intended role boundary
---

Acknowledgement of an HOA request means the contractor has seen it, not that an HOA user has reviewed it. HOA users must not be given an exception to task-edit restrictions to acknowledge requests.

**Why:** The owner explicitly approved rejecting all HOA task edits and hiding the dead HOA admin acknowledgement control, rather than preserving that control's request capability.

**How to apply:** Keep contractor acknowledgement available. HOA request lists and map-jump actions must remain usable independently of task-edit permissions.
