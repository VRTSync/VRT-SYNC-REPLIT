---
name: Community card member-count compatibility
description: Approved behavior for member counts during community card request consolidation.
---

Community cards must preserve displayed member-count zeros rather than showing actual membership totals.

**Why:** The optimization brief conflicted between identical old numbers and real grouped membership counts. The user explicitly chose “Preserve displayed zeros.” This is intentional compatibility, not approval to fix member counts.

**How to apply:** Keep the existing overview summary unchanged. Any correction to visible member counts needs separate approval; avoid an unnecessary membership query while zeros are required.
