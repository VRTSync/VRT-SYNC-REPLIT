# Task #421: Branch detail — tabs must be main layers, with sub-layer toggles beneath

## What & Why

The client portal's branch-detail tab bar currently renders **one tab per `map_layers` row**, so sub-layers appear as top-level tabs:

> Summary · Blue Grass · Landscape Beds · Backflow · Irrigation · Gate Valves · Quick Connects · Wire Splices · Zones · Snowplow · Trees

That's wrong. `Backflow`, `Gate Valves`, `Quick Connects`, `Wire Splices`, and `Zones` are all **sub-layers of Irrigation**; `Blue Grass` and `Landscape Beds` are sub-layers of the community/grounds layer.

**The correct model already exists** in `artifacts/web-portal/public/portal/pages/map.js` (and both mobile map screens): a small set of **main categories** — community, irrigation, snow, trees — selected as tabs/pills, with that category's **sub-layers listed beneath as individually toggleable rows** with color swatches. Mirror that model here.

The API already carries the parent: each layer's `type` field is the `layerKey` (`community`, `irrigation`, `snow`, `trees`, `outline`) — the front end simply isn't grouping by it.

## Done looks like

- Tab bar = **Summary + one tab per main layer that has data**, in `LAYER_HIERARCHY` order: e.g. `Summary · Site Grounds · Irrigation · Snow · Trees`.
- Each tab shows a count = total assets across that category's sub-layers.
- Inside a layer tab, a **sub-layer panel** lists that category's layers (e.g. Irrigation → Backflow 1 · Gate Valves 3 · Quick Connects 1 · Wire Splices 1 · Zones 39), each with:
  - a color swatch showing the **admin-configured layer color** (per #418),
  - an asset count,
  - a checkbox toggling that sub-layer's visibility on the map.
- **All populated sub-layers start visible** when a tab is opened (matching the corrected portal-map behavior from #403); sub-layers with zero geometry render disabled with a "no data" hint.
- Toggling a sub-layer shows/hides only that layer; the map re-fits to visible content.
- The community outline continues to render as neutral context on every tab and is never a tab or a toggle.
- Summary tab still shows all layers together.
- Mobile and the existing portal map are unchanged — this is client-portal only.

## Steps

### 1. API — return the sub-layer key and color

`artifacts/api-server/src/storage.ts`, `getPortfolioBranchDetail()`: include `layerKey`, `subLayerKey`, and `color` for each layer (today it returns only `id`, `name`, `type`, `assetCount`). `type` may stay as-is for compatibility, but the front end should key off `layerKey`.

*(If #418 is landing first, that task already adds `color` — keep them consistent, don't duplicate the field.)*

### 2. Front end — group by main layer

`artifacts/web-portal/public/portfolio/pages/branch-detail.js`:

- Build tabs by grouping `layers[]` on `layerKey`, excluding `outline`. Order and label the tabs from a small hierarchy definition mirroring `LAYER_HIERARCHY` (community → "Site Grounds", irrigation → "Irrigation", snow → "Snow", trees → "Trees"), falling back to a title-cased key for anything unrecognized — **never hardcode the set of categories**, so a new layer type appears automatically.
- Tab asset count = sum of its sub-layers' `assetCount`.
- Keep the existing per-tab accent colors (blue/green/lime/slate/teal) for tab underlines only.

### 3. Front end — sub-layer panel

- In each layer tab, render the sub-layer list above or beside the map, following the visual pattern of the portal map's `.mlp-sublayer-row` (checkbox + color swatch + label + count).
- Initial state: every sub-layer with geometry checked; zero-geometry sub-layers rendered disabled with "no data".
- Toggling calls the map bridge to show/hide that layer id (`showLayerIds` with the current visible set) and re-fits to visible content.
- Sub-layer colors come from each layer's `color` (admin-configured), not the tab accent palette.

### 4. Verify (FB02, PNC — real data)

- Tabs read: `Summary · Site Grounds · Irrigation · Snow · Trees` — **not** one tab per sub-layer.
- Irrigation tab lists Backflow (1), Gate Valves (3), Quick Connects (1), Wire Splices (1), Zones (39) as toggles, all on by default, all rendering on the map in their admin colors.
- Unchecking Zones hides only zones; re-checking restores them; map re-fits both times.
- Site Grounds tab lists Blue Grass (2) and Landscape Beds (11).
- Snow tab lists its sub-layers; those with 0 assets are disabled with "no data" (until #419 lands, expect zeros here).
- Outline never appears as a tab or toggle but is visible as context on every tab.
- Switching tabs repeatedly always renders correctly (depends on #418's fix landing).
