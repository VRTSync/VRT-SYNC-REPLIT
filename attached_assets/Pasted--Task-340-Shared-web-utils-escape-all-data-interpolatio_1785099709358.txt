# Task #340: Shared web utils + escape all data interpolations

**What/why:** Every portal page copy-pastes its own `esc()` helper and several pages escape nothing at all, leaving stored-XSS vectors (contractor/HOA-entered text rendered into admin and portal tables via `innerHTML`). Create one shared utils file and sweep the worst pages.

## Acceptance criteria

1. New file `artifacts/web-portal/public/common/utils.js` exposing `window.VRTUtils = { esc, escAttr, formatDate, formatShortDate, formatCurrency }`. `esc()` escapes `& < > " '`; handles null/undefined by returning `''`; non-strings coerced with `String()`.
2. Loaded FIRST (before any other portal script) via `<script src="/common-static/utils.js">` in all four shells (`admin-shell.html`, `contractor-shell.html`, `hoa-shell.html`, `pm-shell.html`). Add the static mount `app.use("/common-static", express.static(path.join(PUBLIC_ROOT, "common")))` in `server.ts` and include `/common-static` paths in `artifacts/web-portal/.replit-artifact/artifact.toml` services paths. Update the cache-stamp regex in `server.ts` so `/common-static/*.js` also gets `?v=` stamped.
3. All local `esc()` definitions in `public/admin/pages/*.js` and `public/portal/**.js` are deleted; call sites use `VRTUtils.esc` (a local `const esc = VRTUtils.esc;` alias at the top of each IIFE is fine).
4. Zero-escape files get a full sweep — every interpolation of API-derived string data goes through `esc()` (or `escAttr()` inside attribute values): `admin/pages/exports.js`, `admin/pages/xeriscape-planner.js`, `admin/pages/schedules.js`, `admin/pages/users.js`, `admin/pages/assets.js`, `admin/pages/service-schedules.js`. IDs used in `data-id="${x.id}"` and numeric/enum values may stay raw.
5. Remaining pages: no new escaping regressions (leave already-escaped call sites alone).

## Files involved

- New: `public/common/utils.js`
- `src/server.ts`, all 4 shell templates, `.replit-artifact/artifact.toml`
- The six page files listed in AC4; `esc()` deletions across `public/admin/pages/*` and `public/portal/*`

## Must NOT change

- Visual output for benign data (escaping must not double-escape already-escaped strings — remove local esc, don't wrap esc(esc())).
- Page behavior, routing, API calls.
- Script load order beyond inserting utils.js first.

## How to verify

- Create a community named `<img src=x onerror=alert(1)>`; open Admin → Exports and Xeriscape Planner: name renders as literal text, no alert.
- Grep: `grep -rn "function esc(" public/` returns nothing outside `common/utils.js`.
- All four portals load without console errors; spot-check dashboard, tasks, users pages per portal.
