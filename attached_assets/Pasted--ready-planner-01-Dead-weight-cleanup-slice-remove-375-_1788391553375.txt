## Commit 2 · The duplicated portal and template trees — 51 files

### `artifacts/api-server/src/public/` — 46 files

A stale copy of the web portal.

**Three independent proofs it is unreachable**

1. **Nothing serves it.** `grep -rn "express.static\|sendFile" artifacts/api-server/src/` → no results. The api-server serves the API; `web-portal/src/server.ts:130-133` serves static files from `resolveDir("public")`, which resolves inside `artifacts/web-portal/`.
2. **No build copies it.** `artifacts/api-server/build.mjs` performs exactly one `cp`, at `:132` — `lib/db/migrations` → `dist/migrations`.
3. **Strict subset.** Exactly one filename appears here and not in the live tree: `expo-qr.png` — and **that file exists in two other locations** (`artifacts/api-server/public/expo-qr.png`, `.migration-backup/server/public/expo-qr.png`). Nothing is lost.

It does not contain the portfolio portal at all — all 12 of those files are absent, along with `seed-import.js`, `organizations.js`, `organization-detail.js` and `asset-types.js`. That is the staleness signature.

### `artifacts/api-server/src/templates/` — 5 files

`admin-shell.html`, `contractor-shell.html`, `hoa-shell.html`, `landing-page.html`, `pm-shell.html`.

**Every one is a byte-identical duplicate** of the file in `artifacts/web-portal/templates/`, confirmed with `git hash-object`. The directory is **missing `portfolio-shell.html`**, the sixth template in the live tree — same staleness signature.

## Commit 3 · Dead code inside the live planner

### A second, unreachable map implementation

`xeriscape-planner.js` contains **two** map-init paths:

| | Lines | Route it calls | Called? |
|---|---|---|---|
| `ensureMapInit()` + `loadCommunityPolygons()` | `:1035`, `:1056` | `/api/admin/xeriscape/community/:communityId/polygons` | ✅ **live** |
| `initMap()` | `:2634` | `/api/admin/xeriscape/polygons` | ❌ **never called** |

`initMap` is the original KML demo path — its own duplicated ~90-line Leaflet-and-tile setup against the same `#xp-map` element, ending in `showToast('No polygons found in KML')`. The only occurrence of the name `initMap` in the file is its own definition.

### The hard-coded `huntington-trails` fallback

`:2502` — `'/api/admin/xeriscape/records?propertyId=' + (activeCommunityId || 'huntington-trails')`. Same vintage. A hard-coded property id becomes a data-leak shape once this page is client-facing ([spec 07](ready-planner-07-water-savings-page.md)).

**Verify before deleting**

- [ ] `grep -n "initMap" artifacts/web-portal/public/admin/pages/xeriscape-planner.js` → **only the definition line.** Any call site → **stop and report.**
- [ ] `grep -rn "xeriscape/polygons'" artifacts/` → only the dead `initMap` body. The `community/:id/polygons` route is a **different string** and must survive.

**Then**

- [ ] Delete `initMap()` (`:2634` to the end of that function) and anything only it reaches.
- [ ] Delete `GET /api/admin/xeriscape/polygons` (`routes.ts:1176-1208`) and its `huntington-trails-xeriscape.kml` file read.
- [ ] Delete `artifacts/web-portal/public/admin/data/huntington-trails-xeriscape.kml`.
- [ ] Delete the `huntington-trails` fallback at `:2502`. With no active community, do not fetch — show the existing empty state.
- [ ] Commit message: `Remove dead KML map path from xeriscape planner`
- [ ] **No refactoring. Deletions only.**
